---
name: trend-scout
description: Research trending topics, viral angles, and high-resonance themes for your niche. Use when brainstorming post ideas, finding content opportunities, or building a content queue in ideas.md.
---

1. Read `brand.md` to extract the niche, target audience, and brand positioning. If `brand.md` is missing, tell the user to run `/brand` first.

2. Read `likes.md` if present to identify which topics, angles, or content styles previously received high praise, and which to avoid.

3. Investigate active trends and conversations in the niche using `search_web`. Prioritize:
   - Recent industry news, paradigm shifts, or breaking updates.
   - Contrarian viewpoints challenging conventional wisdom.
   - Evergreen problems your target audience struggles with right now.
   - High-performing formats (framework breakdowns, "stop doing X", data-backed comparisons).

4. Curate 3 to 5 distinct post angles. For every angle, formulate:
   - **Working Title & Hook**: A punchy 1-line premise that stops the scroll.
   - **Core Value / Takeaway**: The specific insight, statistic, or lesson delivered.
   - **Recommended Format**: Single post (1080x1080 or 1080x1350) vs multi-slide carousel.
   - **Archetype**: (e.g., Contrarian Take, Step-by-step Framework, Data Comparison, Visual Quote).

5. Update or append to `ideas.md` in the workspace root. Keep an active "Backlog" section and an "In Progress / Selected" section.

6. Present the 3-5 options to the user with a recommended pick, and ask which one they want to advance to `/copy-hook` or `/design-html`.
